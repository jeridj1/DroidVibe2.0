# DroidVibe Example Sketches

Starter sketches and templates for use with the DroidVibe mobile app.

## Sketches

| File | Description |
| --- | --- |
| `blink.ino` | Blink the built-in LED (Arduino Hello World) |

## Usage

Open the DroidVibe app, navigate to the **Sketches** tab, and tap **New** to
create a blank sketch. Paste the example code, select your board, and tap
**Compile** to build. Connect your board via USB OTG and tap **Upload** to
flash.
